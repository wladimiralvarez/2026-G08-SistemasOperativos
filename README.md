# 2026-G08-SistemasOperativos

**mishell** — Shell con pipes, redirección y manejo de señales.
Tarea 1 · Sistemas Operativos 2026 · Universidad de Concepción · Grupo 8

## Compilación

Requiere Linux (o WSL) con `gcc` y `make`:

```bash
sudo apt install build-essential
```

Desde la raíz del repositorio:

```bash
make
```

Genera el ejecutable `./mishell`. 

Para limpiar:

```bash
make clean
```

## Ejecución

```bash
./mishell
```

Se sale con `exit`, `exit N` o `Ctrl+D`.
